# Голоса Akali

Эта папка не коммитится в git (см. `.gitignore`) — только эта документация.

## Piper (нейронный, оффлайн)

Piper-голоса (`*.onnx` + `*.onnx.json`) скачиваются автоматически при
первом запуске. Дефолт: `ru_RU-dmitri-medium` (мужской «Джарвис»).

## XTTS v2 (клонирование голоса)

Чтобы включить XTTS v2 (Coqui), нужно:

1. Установить пакет:
   ```
   pip install TTS
   ```
   (~2 ГБ из-за torch — кликни «Установить недостающее» в Настройках)

2. Положить **WAV-сэмпл** голоса (6–30 сек чистой речи без шума и музыки)
   в этот файл:
   ```
   voices/jarvis_reference.wav
   ```
   Формат: 16-bit PCM, моно, 22.05/24/44.1 кГц.

3. Перезапустить приложение. В Настройках → Голосовой ответ → Движок
   автоматически появится опция **xtts (клонированный голос Джарвиса)**.
   В режиме `auto` он используется по умолчанию, если готов.

## Кэш WAV

Прогретые фразы кладутся в `~/.cache/akali/tts/`. Кэш привязан к движку и
голосу — при смене любого ключа кэш генерируется заново.
