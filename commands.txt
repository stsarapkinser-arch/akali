# ==========================================================
# БАЗА ЗНАНИЙ АССИСТЕНТА "АКАЛИ" (Kali Linux + KDE Plasma 6)
# Формат: bash_команда -> фраза_1, фраза_2, фраза_3
#
# ПРАВИЛА ЗАПОЛНЕНИЯ:
#   1. После команды поставь '&' — если это GUI или фоновое приложение
#      (вывод stdout НЕ перехватывается, окно живёт самостоятельно).
#   2. Без '&' — консольная утилита, stdout/stderr печатаются в терминал.
#   3. TUI-программы (htop, msfconsole, wifite, setoolkit) запускай через
#      `konsole -e <cmd> &`, иначе они стартуют без терминала и не отрисуются.
#   4. xdotool НЕ работает под Wayland — используй qdbus → KWin.
#      На Plasma 6 бинарь может называться qdbus6 (пакет qt6-tools).
#   5. Не добавляй интерактивные команды (apt без -y, ssh с паролем) —
#      они подвесят subprocess.run, пока не реализуем pexpect-обвязку.
#   6. Команды, требующие root: poweroff/reboot/suspend идут через systemctl
#      и пускаются обычным юзером через polkit. Сетевые операции типа
#      `systemctl restart NetworkManager`, `tcpdump`, `airmon-ng` — нужен
#      root. На Kali, где сессия часто под root, это работает «как есть».
#
# ОПЦИОНАЛЬНЫЕ ПАКЕТЫ (доставь, если каких-то команд нет):
#   sudo apt install -y playerctl mtr-tiny lm-sensors tree
#   sudo apt install -y kali-tools-top10 kali-linux-default
# ==========================================================
